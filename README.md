# 🎮 NroGT

NroGT hỗ trợ **Windows, Android và iOS**.

Các phiên bản mới nhất được phát hành tại mục **Releases** của repository này.

## 📥 Tải game

👉 **[TẢI PHIÊN BẢN MỚI NHẤT](https://github.com/thachdeptrai/NroGT-Releases/releases/latest)**

Trong phần **Assets**, hãy chọn file phù hợp với thiết bị của bạn:

| Thiết bị | File cần tải |
|---|---|
| 🖥️ Windows PC | `NroGT.zip` |
| 🤖 Android | `NroGT.apk` |
| 🍎 iPhone / iPad | `NroGT.ipa` |

---

## 🖥️ Windows

Tải:

`NroGT.zip`

### Cách cài đặt

1. Tải `NroGT.zip` trong **Releases**.
2. Giải nén file ZIP.
3. Mở thư mục vừa giải nén.
4. Chạy:

`NroGT.exe`

> ⚠️ Không chạy game trực tiếp bên trong file ZIP.  
> Hãy giải nén toàn bộ thư mục trước khi mở game.

---

## 🤖 Android

Tải:

`NroGT.apk`

### Cách cài đặt

1. Tải `NroGT.apk`.
2. Mở file APK.
3. Nếu Android yêu cầu quyền cài ứng dụng từ nguồn bên ngoài, hãy cho phép trình duyệt hoặc trình quản lý file đang sử dụng.
4. Chọn **Cài đặt**.
5. Mở **NroGT** sau khi cài xong.

> Nếu đã cài phiên bản cũ, bạn có thể thử cài trực tiếp bản mới để cập nhật.

---

## 🍎 iOS / iPadOS

Tải:

`NroGT.ipa`

File IPA không thể cài trực tiếp bằng cách nhấn vào file trên iPhone/iPad.

Bạn cần sử dụng phương thức sideload/sign IPA phù hợp với thiết bị của mình.

### Còn Đòi Link TF thì có lồn tiền hỏi ít thôi
### File cần sử dụng

`NroGT.ipa`

> ⚠️ Bản IPA được cung cấp dưới dạng **unsigned IPA**.  
> Người dùng cần tự ký (sign) ứng dụng trước khi cài đặt lên thiết bị.
